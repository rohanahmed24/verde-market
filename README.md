# Verde Market

A multi-page responsive storefront concept used to explore motion-rich frontend implementation.

## Highlights

- Multi-page product, journal, story, location, account, and checkout flows
- GSAP and ScrollTrigger reveals, parallax, magnetic controls, and cursor interactions
- Lenis smooth scrolling
- Responsive static HTML pages with reusable visual patterns

## My role

Frontend implementation and interaction work from a Google Stitch design export. This is a portfolio concept, not a production commerce service; checkout and account pages demonstrate interface flows only.

## Stack

HTML · Tailwind CSS · GSAP · ScrollTrigger · Lenis

## Run locally

No application build is required. Clone the repository and open `index.html` in a browser.

Optional HTML validation:

```bash
npm install
npm run lint
```
