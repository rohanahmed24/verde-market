## ✨ Overview

Verde Market is a **production-ready, multi-page organic grocery e-commerce platform** designed to showcase premium web animation techniques. Built from a Google Stitch design export, every section has been layered with world-class GSAP animations to deliver a jaw-dropping visual experience.

> _"Fresh from the farm, straight to your door."_

---

## 🎬 Animations & Interactions

| Feature | Library | Description |
|---|---|---|
| 🌀 Smooth Scroll | Lenis | Buttery-smooth, physics-based scrolling |
| 🎯 Scroll Triggers | GSAP ScrollTrigger | Section reveals keyed to scroll position |
| ✍️ Text Reveal | GSAP + Word Split | Words slide up from invisible clip masks |
| 🃏 3D Card Tilt | GSAP | Product cards tilt in 3D on mouse move |
| 🧲 Magnetic CTAs | GSAP | Buttons subtly pull towards the cursor |
| 🌊 Parallax | GSAP | Hero blob & story image scroll at different rates |
| 🖱️ Custom Cursor | GSAP | Ring-and-dot cursor with hover state transitions |
| ⏳ Preloader | GSAP | Animated bouncing dots exit before content reveals |
| 📣 Marquee | GSAP | Infinite announcement strip, pauses on hover |
| 🌀 Floating Cards | GSAP | Hero trust badges float with sine-wave motion |

## 🚀 Quick Start

No build step needed — just open any HTML file directly in your browser:

```bash
# Clone the repo
git clone https://github.com/rohanahmed24/verde-market.git
cd verde-market

# Open in browser
open index.html
# or
xdg-open index.html
```

## 🛠️ Tech Stack

```
HTML5 + Tailwind CSS     →  Structure & Styling
GSAP 3.12.5              →  Animation engine
  ├─ ScrollTrigger       →  Scroll-based animations
  ├─ CustomEase          →  Branded easing curves
  └─ ScrollToPlugin      →  Smooth anchor scrolling
Lenis 1.0.42             →  Smooth scroll momentum
Google Stitch            →  UI Design & Asset Export
```

---

## 🎨 Design System

Three custom GSAP eases define the Verde brand motion language:

| Ease | Curve | Use Case |
|---|---|---|
| `verdeIn` | Elastic settle | Headlines & hero entrances |
| `verdeSoft` | Smooth cubic | Subtle fades & UI elements |
| `verdeSnap` | Snap + overshoot | CTAs & card pops |
